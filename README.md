# Refit AI

Website for Refit AI, an AI business workflow redesign consultancy. Businesses say where they want AI to improve how they run (operations, marketing, customer handling, billing). Refit AI redesigns those processes with them. The client owns everything that is built.

## Mockups

`mockups/` holds three aesthetic directions for the site. All are dark mode, black and white, with no eyebrow labels above headings. The copy is identical across the three so the comparison is about look alone.

| File | Direction |
| --- | --- |
| `mockups/option-a-editorial.html` | Serif display, warm near-black, hairline rules, magazine pacing |
| `mockups/option-b-precision.html` | Grotesk and mono, pure black, visible grid, every section a table |
| `mockups/option-c-monolith.html` | Heavy display type, cool black alternating with white sections, oversized headlines |

Open `mockups/index.html` in a browser to switch between them. Each page is a single self-contained HTML file with no build step, and is responsive down to phone width. Fonts load from Google Fonts.

Text in square brackets, such as `[YOUR NAME]` and `[YOUR EMAIL]`, is a placeholder to fill in. The garden design studio example is illustrative and should be replaced with a real engagement.
