# Refit AI

Website for Refit AI, an AI business workflow redesign consultancy. Businesses say where they want AI to improve how they run (operations, marketing, customer handling, billing). Refit AI redesigns those processes with them. The client owns everything that is built.

## The site

`index.html` is the site: a single self-contained HTML page with no build step, responsive down to phone width. Fonts (Archivo and IBM Plex Mono) load from Google Fonts.

The design is the "Precision" direction: pure black, white type, a visible grid frame, and each section laid out as a table with a defined output per step. No eyebrow labels above headings.

Text in square brackets, such as `[YOUR NAME]` and `[YOUR EMAIL]`, is a placeholder to fill in. The garden design studio example is illustrative and should be replaced with a real engagement.

## Earlier directions

`mockups/` keeps the two directions that were not chosen (Option A, Editorial and Option C, Monolith) for reference. Open `mockups/index.html` to compare them with the site.
